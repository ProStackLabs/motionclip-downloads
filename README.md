# MotionClip desktop downloads

Compiled installers and update metadata for MotionClip. Source is maintained separately.

Windows builds in this repository are currently unsigned testing releases. Windows may show a security warning. These releases do not certify the full editing workflow. macOS updates are not available until signing and native upgrade validation are complete.

Inside MotionClip, open Settings → Updates. Download an available update, close projects and wait for assistants to finish, then select Restart to update. The source repository and GitHub access are not required.
